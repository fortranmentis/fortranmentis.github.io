# Sang Hak Lee · Portfolio

Bilingual, English-first portfolio for **https://fortranmentis.github.io/**.

## Contents

- `index.html`: English portfolio
- `ko/index.html`: Korean portfolio
- `style.css`: responsive light visual system with large type, blue actions, a dark product spotlight, and teal gradients
- `script.js`: accessible project filters; all content remains available without JavaScript
- `assets/`: local graphics and public project screenshots

## Preview

```sh
python3 -m http.server 8765
```

Open http://localhost:8765/. No build step or third-party dependencies are required.

## Deploy

GitHub Pages serves the root of the `main` branch. Keep `.nojekyll` in place.
After editing project content, update both language pages, metadata and review dates.
