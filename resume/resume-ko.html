① 감시·예측 산출물 적재 파이프라인

GeoSR · 2025.06 – 2026.04

4개 기관(KIOST·NIFS·KHOA·KOPRI)이 매월 보내는 11종 해양·기상 감시·예측 산출물(NetCDF·CSV)을 검증해 DB에 적재하고 GeoServer 레이어로 발행하는 폐쇄망 파이프라인

역할
데이터 모델 설계, 규격 검증·공간 변환·ETL 개발 및 기술 문서 작성
설계
산출물 메타데이터(자료종류·연월·감시/예측·등록 일시·공개 여부)와 검증 결과, 관측·예측 값을 별도 테이블로 분리. 관리 테이블은 (자료종류, 연도, 월, 구분) 조합으로 조회·갱신하고, 검증 결과·값은 파일명으로 연결해 원본–검증–적재를 추적
검증
입력 규격표 대비 Class·Variable·Level(depth)·Unit 항목을 자동 비교해 파일별 통과 여부와 오류 항목을 기록
처리
Python·Shell·Docker 파일 감시, 래스터 재격자화·재투영, U/V 성분에서 유속·방향 산출, Upsert·트랜잭션·재처리, 스케줄링
설계 이유
검증 결과를 별도 테이블로 분리해 파일별 불합격 원인을 조회할 수 있도록 하고, 파일 서명 비교로 변경되지 않은 파일의 반복 규격 검증을 줄임
결과
항목별 판정 보고서, GeoTIFF·해류 벡터 CSV, 지정 GeoServer 레이어

변경 감지·증분 처리 파일별 크기·수정시각·SHA-256을 처리 로그(filename·size·mtime·sha256·processed_at)로 관리하고, 변경된 파일만 규격 검증을 다시 수행하도록 구현했습니다.
